# Phase 0 Inventory

## Repo Shape
- `.astro/`: Astro-generated types and content metadata; dirty after build/audit runs.
- `.playwright-cli/`: local Playwright helper state generated by audit tooling.
- `.playwright-mcp/`: browser automation support files.
- `artifacts/`: generated audit or experiment outputs from prior runs.
- `axiom-landscaping-demo/`: concept demo app/source for landscaping proof.
- `axiom-restaurant-demo/`: concept demo app/source for restaurant proof.
- `axiom-roofing-demo/`: concept demo app/source for roofing proof.
- `dist/`: current static build output.
- `docs/`: project documentation and Phase 0 audit artifacts.
- `functions/`: Cloudflare Pages Functions and shared server utilities.
- `migrations/`: D1 schema migration files.
- `node_modules/`: installed dependencies.
- `omniscient-backend/`: non-marketing backend/service workspace.
- `output/`: generated audit output, including motion audit assets.
- `public/`: static assets, redirects, headers, fonts, images, icons, robots, sitemap.
- `screenshots/`: visual captures from prior QA runs.
- `scripts/`: build/prerender/intake smoke scripts.
- `src/`: Astro pages, layouts, public React islands, legacy SPA code, styles, hooks, and admin UI.
- `test-results/`: Playwright output from prior runs.
- `tests/`: current automated smoke/motion/intake tests.

## Existing Design Token Surface
### CSS variables in `src/styles/tokens.css`
- Colors: `--bg-base`, `--surface-*`, `--hairline*`, `--text-*`, `--accent*`, `--error-*`, `--selection-*`, `--nav-*`.
- Typography: `--font-display`, `--font-body`, `--font-mono`, `--font-accent`.
- Layout spacing: `--content-width`, gutters, section spacing.
- Shape: `--radius-card`, `--radius-component`.
- Motion: `--transition-standard`, `--reveal-duration`, `--reveal-distance`, `--reveal-stagger`.
- Effects: extensive shadow tokens for cards, nav, buttons, fields, brand rings.

### Tailwind extension in `tailwind.config.js`
- Custom colors wired to CSS vars: `background`, `surface`, `elevated`, `hairline`, nested `text.*`, nested `accent.*`, and legacy `axiom.*`.
- Font families still mapped to `Inter`, `Inter Display`, `Fraunces`, `JetBrains Mono`, `General Sans`.
- Type scale: `display`, `h1`, `h2`, `h3`, `h4`, `bodyLg`, `body`, `bodySm`, `eyebrow`, `metric`, `button`.
- Spacing: `section`, `section-lg`.
- Shape/effects: `maxWidth.container`, `borderRadius.card`, `borderRadius.pill`, `boxShadow.card`.

### Gaps in current token system
- No single typed token source in code.
- Multiple overlapping aliases (`accent`, `accent-v2`, `axiom-accent`, `accent-current`).
- Rounded-pill CTAs and 16px card radii conflict with the planned architectural direction.
- Current fonts and type hierarchy do not match the approved `Cormorant Garamond` + `Archivo` system.
- Existing tokens mix foundational values with component-specific shadow/effect values.

### Current intake backend behavior
- `functions/api/contact.ts`: validates quick-contact payload and proxies into intake.
- `functions/api/intake.ts`: validates intake, rate-limits at 5 submissions / 10 min / IP, optional Turnstile verification, stores inquiry in D1, sends internal and confirmation email via Resend.
